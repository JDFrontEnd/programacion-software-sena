Las herramientas

SQLite y DB Browser for SQLite

SQLite · el motor
  • Base de datos relacional que usa SQL.
  • Toda la base vive en un solo archivo (.db, .sqlite).
  • No necesita servidor: no hay que instalar ni encender nada aparte.
  • La usan los celulares, los navegadores y muchas aplicaciones de escritorio.
DB Browser for SQLite · la interfaz
  • Programa gratuito para crear y ver bases SQLite con ventanas y botones.
  • Es a SQLite lo que Compass es a MongoDB.
  • Se descarga en sqlitebrowser.org para Windows, macOS y Linux.
Las cuatro pestañas de DB Browser · toque cada una
Repaso · Tipos de dato en SQL

¿Qué tipo de dato uso?

En SQLite es más sencillo: acepta todos esos nombres, pero los guarda en solo cinco clases: INTEGER, REAL, TEXT, BLOB y NUMERIC. Por ejemplo, VARCHAR(50) se guarda como TEXT y no limita los 50 caracteres; BOOLEAN se guarda como 0 y 1, y las fechas como texto '2026-11-11'.
Práctica · elija el tipo para cada campo
Repaso · Restricciones (constraints)

Reglas que protegen los datos

Para precisar: la FOREIGN KEY obliga a que el valor exista como PRIMARY KEY en la otra tabla (así se arma la relación). El INDEX no es una restricción: solo acelera las búsquedas.
Pruebe cada regla con SQLite real
CREATE TABLE Clientes (
  IdCliente INTEGER PRIMARY KEY AUTOINCREMENT,
  Documento TEXT NOT NULL UNIQUE,
  Nombre    TEXT NOT NULL,
  Edad      INTEGER CHECK (Edad >= 18),
  Ciudad    TEXT DEFAULT 'Medellín'
);

  Paso 4 · Tabla Productos con FOREIGN KEY
  
La tabla que guarda la relación

  

    
    

      

      

      

    

  

  

    
FOREIGN KEY ("IdMarca") REFERENCES "Marcas"("IdMarca") se lee: "el IdMarca de cada producto debe existir en la tabla Marcas". Por eso Marcas se crea primero.

    
Ojo: SQLite solo revisa las claves foráneas si están activadas. DB Browser las activa por defecto (Preferencias › Base de datos › Claves foráneas). En otros programas se activa con PRAGMA foreign_keys = ON;

  Paso extra · Un paso más allá del ejemplo
  
¿Y las marcas sin productos?

  
Agregamos la marca Apple sin productos. INNER JOIN solo muestra lo que tiene pareja en las dos tablas; LEFT JOIN muestra todas las filas de la tabla de la izquierda, aunque no tengan pareja.
