Actualizar registros

Las partes de un UPDATE

Toque cada parte de la instrucción.
Se lee así: "en la tabla Marcas, pon NombreMarca igual a 'Sony' solo en la fila cuyo IdMarca es 6".
La regla de oro: el WHERE decide cuántas filas cambian. Sin WHERE, el UPDATE cambia todas las filas de la tabla.
Actualización individual

Cambiar una sola fila

Para cambiar una fila, el WHERE usa la clave primaria: IdMarca nunca se repite, así que es imposible tocar otra fila por error.

Se pueden cambiar varias columnas a la vez separándolas con comas después del SET.

Filtrar por el nombre (WHERE NombreMarca = 'Sonyy') también funciona, pero si hubiera dos filas con ese nombre cambiarían las dos.
Actualización masiva

Cambiar muchas filas de una vez

NombreMarca || ' *' toma el valor que ya tiene la columna y le pega el texto ' *' al final. El operador || une textos (concatena).

Ojo: en SQLite 'Sony' + ' *' no une textos: intenta sumar números y da 0. Para unir textos se usa ||.

Actualizar usando el valor actual

El nuevo valor puede calcularse a partir del que ya existe. Así se hacen los aumentos de precio, los descuentos o las correcciones de formato.

Un hábito que evita desastres

Primero SELECT, después UPDATE o DELETE

  1. Escriba el WHERE en un SELECT * y ejecútelo.
  2. Revise que salgan exactamente las filas que quiere cambiar o borrar.
  3. Cambie SELECT * por UPDATE … SET … o por DELETE, dejando el mismo WHERE.
  4. En DB Browser, revise el resultado y pulse Escribir cambios (Ctrl + S). Si algo salió mal, pulse Revertir cambios: deshace todo lo que no se ha escrito.

  Cuando la fila está relacionada
  
¿Se puede borrar Samsung?

  

    

      
Samsung (IdMarca 1) tiene productos que lo usan como clave foránea. Si se borrara, esos productos quedarían apuntando a una marca que no existe. La FOREIGN KEY lo impide.

      

    

    

      
Tres formas de resolverlo

      

        
1 · Borrar primero los hijos
Se borran los productos de la marca y luego la marca. Es la forma más segura: usted decide qué se pierde.

        
2 · ON DELETE CASCADE
Si la FK se crea con REFERENCES Marcas(IdMarca) ON DELETE CASCADE, al borrar la marca SQLite borra solo sus productos. Cómodo, pero peligroso: un DELETE puede llevarse muchas filas.

        
3 · ON DELETE SET NULL
Con ON DELETE SET NULL los productos se quedan, pero su IdMarca pasa a NULL ("sin marca").

      

      

    

  







  Consulta por datos y con nombramiento
  
Elegir columnas y renombrarlas con AS

  

    

      
Consulta por datos: en lugar de *, se escriben las columnas que se quieren ver, en el orden que se quieran ver.

      
Consulta con nombramiento (alias): AS cambia el título de la columna en el resultado. La tabla no cambia.

      
En la clase 5 usamos AS para dar apodo a las tablas (Productos AS p). Aquí lo usamos para las columnas. Si el alias tiene espacios, va entre comillas dobles: AS "Precio con IVA".
