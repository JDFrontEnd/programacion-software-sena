Gestores de base de datos

¿Qué es un SGBD (DBMS)?

Un sistema gestor de base de datos es un conjunto de programas, invisibles para el usuario final, con el que se administra y gestiona la información de una base de datos.

El lenguaje SQL nuevo

Structured Query Language

SQL es el lenguaje estándar para hablar con las bases de datos relacionales. Sus instrucciones se agrupan en cuatro familias.

Claves y relaciones nuevo

Cómo se conectan las tablas

La clave primaria (PK) identifica cada fila sin repetirse. La clave foránea (FK) apunta a la PK de otra tabla. Pasa el cursor o toca un campo para ver la relación.

estudiantes

id_estudiante PK
nombre VARCHAR
carrera VARCHAR

matriculas

id_matricula PK
id_estudiante FK
id_clase FK
nota DECIMAL

clases

id_clase PK
clase VARCHAR
semestre INT

Un estudiante puede tener muchas matrículas y una clase puede tener muchos estudiantes: relación muchos a muchos resuelta con una tabla intermedia.

Transacciones confiables nuevo

Las propiedades ACID

Una transacción agrupa varias operaciones que deben ejecutarse como una sola. Ejemplo: transferir $100.000 de la cuenta A a la cuenta B.
